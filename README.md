# Gabay: Filipino Sign Language (FSL) Recognition App
Gabay (Tagalog for "Guide") is an award-winning Android-based educational platform designed to bridge the communication gap between the Deaf and hearing communities in the Philippines. By utilizing real-time Computer Vision, the app translates Filipino Sign Language (FSL) gestures into text and provides interactive learning modules.

## Achievements
- **Best Overall Exhibit** – STI College SJDM (2025)

- **1st Best in Implementation** – STI College SJDM (2025)

- **1st Best in Communication** – STI College SJDM (2025)

- **1st Best in Use of College Theme** – STI College SJDM (2025)

## Key Features
- **Real-time FSL Recognition:** Instant translation of hand signs using the device camera.

- **Interactive Lessons:** Structured curriculum for learning FSL alphabet, common phrases, and grammar.

- **Progress Tracking:** Quiz modules to assess user mastery of signs.

- **Offline Capability:** Optimized for mobile performance without requiring a constant internet connection.

## Technical Stack
- **Development Environment:** Android Studio

- **Languages:** Java / Kotlin

- **Machine Learning:** TensorFlow Lite (Custom-trained models)

- **Computer Vision:** OpenCV for image preprocessing and hand tracking

- **UI/UX:** XML with Material Design 3
